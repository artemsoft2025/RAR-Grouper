================================================================================
ARCH GROUPER v2.2
Умная группировка файлов в архивы по лимиту размера
================================================================================
--------------------------------------------------------------------------------
ЗАЧЕМ ЭТА ПРОГРАММА
--------------------------------------------------------------------------------
Когда нужно залить много больших файлов (видео, бэкапы, образы дисков) в
облако или Telegram, стандартный архиватор предлагает два неудобных пути:
1. Сделать один гигантский архив и потом порезать его на куски.
2. Сразу разбить на тома (RAR part1, part2, part3...).
В обоих случаях, чтобы достать ОДИН нужный файл, придётся скачать ВЕСЬ архив
целиком. Это долго, дорого и неудобно.
Arch Grouper решает эту проблему иначе: он создаёт МНОГО САМОСТОЯТЕЛЬНЫХ,
НЕЗАВИСИМЫХ архивов. Вы указываете папку с файлами и желаемый размер архива
(например, 3 ГБ). Программа сама набирает в каждый архив столько файлов,
сколько влезает в лимит, и создаёт следующий. Каждый архив можно скачать
отдельно — не нужно тянуть всё сразу.
--------------------------------------------------------------------------------
ОСНОВНЫЕ ВОЗМОЖНОСТИ
--------------------------------------------------------------------------------
[+] Поддержка двух архиваторов: RAR (Rar.exe) и 7-Zip (7z.exe).
[+] Автоматический поиск установленных архиваторов при запуске.
[+] Возможность указать путь к архиватору вручную (для портативных версий).
[+] Три формата архивов: RAR, 7z, ZIP.
[+] Группировка файлов в независимые архивы по заданному лимиту (ГБ).
[+] Семь вариантов автоматического именования архивов:
    - по первым трём файлам в наборе (с умной обрезкой длинных имён);
    - префикс + номер;
    - имя папки + номер;
    - по первому файлу;
    - по диапазону чисел (video_001-015.rar);
    - дата + номер;
    - свой шаблон с плейсхолдерами.
[+] Автоматическая замена пробелов на «_» в именах архивов.
[+] Обработка файлов больше лимита: разбить на тома / отдельный архив /
    пропустить.
[+] Рекурсивный обход подпапок (по желанию).
[+] Фильтр «только видеофайлы» (mp4, mkv, avi, mov и др.).
[+] Сохранение структуры папок внутри архива (относительно папки-источника).
[+] Передача списка файлов архиватору через @listfile (файл-список).
    Это позволяет обрабатывать папки с десятками тысяч файлов без ошибок
    «слишком длинная командная строка».
[+] Лимит файлов на один архив — 2000. Если файлов больше, программа
    разобьёт их на несколько архивов, даже если по размеру они могли бы
    влезть в один. Это нужно, чтобы файл-список не разрастался до гигабайта.
[+] Уровень сжатия: m0 (без сжатия), m1, m3, m5.
[+] Пароль на архив и опциональное шифрование имён файлов.
[+] Галочка «Сохранить пароль» (по умолчанию выключена).
    Если включена — пароль шифруется и привязывается к текущему ПК.
    Скопированный на другой компьютер файл настроек не позволит
    восстановить пароль.
[+] Запись для восстановления (-rr5%, только RAR).
[+] Проверка архива после создания.
[+] TXT-отчёт: человекочитаемый список файлов в каждом архиве.
[+] JSON-отчёт: машиночитаемый вариант для скриптов и поиска.
[+] Предпросмотр разбиения до старта.
[+] Создание подпапки для архивов (по имени источника).
[+] Сохранение всех настроек между запусками.

СИСТЕМНЫЕ ТРЕБОВАНИЯ
--------------------------------------------------------------------------------
- Windows 7 / 8 / 10 / 11 (x64).
- Один из архиваторов:
  * WinRAR (файл Rar.exe, обычно "C:\Program Files\WinRAR\Rar.exe")
  * 7-Zip (файл 7z.exe, обычно "C:\Program Files\7-Zip\7z.exe")
    Поддерживается 7-Zip версий 21.x, 22.x, 23.x, 24.x, 25.x, 26.x.
    Если у вас 7-Zip 26.06 или новее — программа использует ключ -bb0
    вместо -idq (в этой версии 7-Zip ключ -idq работает некорректно).
Программа не требует установки. Достаточно запустить Arch_Grouper.exe.
--------------------------------------------------------------------------------
БЫСТРЫЙ СТАРТ
--------------------------------------------------------------------------------
1. Запустите Arch Grouper (Arch_Grouper.exe).
2. В панели «Источник» укажите папку с файлами.
3. В панели «Куда сохранять» укажите папку для архивов.
4. Задайте лимит (например, 3.0 ГБ на архив).
5. В панели «Параметры архиватора» выберите архиватор и формат.
6. (Необязательно) Настройте имена архивов, пароль, отчёты.
7. Нажмите «👁 Предпросмотр», чтобы увидеть план разбиения.
8. Нажмите «▶ Старт».
По завершении рядом с архивами появятся TXT- и JSON-отчёты со списком
файлов. Загрузите их вместе с архивами в облако — и перед скачиванием
сразу будет видно, что внутри.
--------------------------------------------------------------------------------
РЕЖИМЫ РАБОТЫ
--------------------------------------------------------------------------------
«Быстро» (fast)
    Набор файлов по СУММЕ ИСХОДНЫХ размеров. Архив создаётся один раз.
    Самый быстрый режим. Подходит для видео, так как оно почти не сжимается,
    и итоговый размер архива близок к сумме исходников.

«Точно» (exact)
    Пересборка архива с учётом ИТОГОВОГО размера, чтобы максимально
    заполнить лимит. Медленнее, потому что архив может пересобираться
    несколько раз. Имеет смысл для хорошо сжимаемых данных (текст, фото,
    документы).
    Примечание: в текущей версии режим работает так же, как «Быстро»
    (без пересборки). Он оставлен в интерфейсе на будущее.

«Гибрид» (hybrid, по умолчанию)
    Быстрый набор + автоматическая дозаполнение, если архив получился
    заметно меньше лимита (заполнен менее чем на 85%). Программа берёт
    файлы из следующего набора и добавляет их в текущий архив, если они
    влезают по размеру. Хороший компромисс между скоростью и плотностью:
    для видео разница минимальна, а вот для мелких файлов архивы становятся
    заметно плотнее. Количество попыток дозаполнения задаётся параметром
    «макс. попыток» (по умолчанию 3).
--------------------------------------------------------------------------------
ВАРИАНТЫ ИМЁН АРХИВОВ
--------------------------------------------------------------------------------
По первым трём файлам    video_001__video_002__video_003_001.rar
(при длинных именах — умная обрезка с диапазоном)
Префикс + номер          videos_001.rar
Имя папки + номер        MyVideos_001.rar
По первому файлу         IMG_2034.rar
По диапазону чисел       video_001-015.rar
Дата + номер             2026-11-18_001.rar
Свой шаблон              {prefix}_{n}.rar

Плейсхолдеры для своего шаблона:
  {prefix}  — префикс из поля «Префикс» (или имя папки-источника)
  {folder}  — имя папки-источника
  {n}       — номер набора (001, 002, ...)
  {date}    — текущая дата (ГГГГ-ММ-ДД)
  {first}   — имя первого файла в наборе (без расширения)
  {last}    — имя последнего файла в наборе (без расширения)
  {files3}  — первые три имени через «__»

Галочка «Заменить пробелы на _» (включена по умолчанию) убирает пробелы
из имени архива — это полезно для облачных хранилищ и Telegram.
--------------------------------------------------------------------------------
ПАРОЛЬ И ШИФРОВАНИЕ
--------------------------------------------------------------------------------
Пароль на архив задаётся в панели «Параметры архиватора».
Рядом с полем пароля есть кнопка «👁» — показать/скрыть введённые символы.

Галочка «шифровать имена» доступна только для форматов RAR и 7z.
Для ZIP она автоматически отключается, так как формат ZIP не поддерживает
шифрование имён файлов. Для RAR используется ключ -hp, для 7-Zip — -mhe=on.

Галочка «сохранить пароль» (по умолчанию выключена) позволяет сохранить
пароль между запусками. При этом пароль не хранится в открытом виде:
он шифруется и привязывается к текущему компьютеру (имя пользователя,
имя компьютера, серийный номер системного диска). Если файл настроек
скопировать на другой ПК, пароль не восстановится.

ВАЖНО: это простая защита «от дурака», а не криптостойкое хранилище.
Не используйте её для критически важных паролей.
--------------------------------------------------------------------------------
ФАЙЛЫ БОЛЬШЕ ЛИМИТА
--------------------------------------------------------------------------------
Если отдельный файл больше заданного лимита, программа предложит три
варианта:

«Разбить на тома»     — создать многотомный архив с томами по лимиту.
                        Например, файл 8 ГБ при лимите 3 ГБ будет разбит
                        на 3 тома (3 + 3 + 2 ГБ).

«Отдельный архив»     — положить файл в отдельный архив как есть
                        (с предупреждением, если итог всё ещё больше лимита).

«Пропустить»          — не архивировать этот файл, записать в лог.
--------------------------------------------------------------------------------
ОТЧЁТЫ
--------------------------------------------------------------------------------
TXT-отчёт (<имя_папки>_contents.txt)
    Человекочитаемый список: какой архив, сколько файлов, какие именно,
    размер каждого. Удобно открыть в Блокноте и посмотреть перед скачиванием.

JSON-отчёт (contents_ГГГГ-ММ-ДД.json)
    Машиночитаемый формат. Пригодится, если вы захотите написать скрипт
    для поиска «в каком архиве лежит файл X».

Оба отчёта создаются в папке с архивами (или в подпапке, если включена
опция «Создавать подпапку»).
--------------------------------------------------------------------------------
ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ
--------------------------------------------------------------------------------
В: Какой архиватор выбрать — RAR или 7-Zip?
О: Если установлены оба, по умолчанию выбирается RAR. Если только один —
   он и будет выбран. Если ни одного — программа попросит указать путь
   к исполняемому файлу вручную.

В: Можно ли использовать ZIP?
О: Да. ZIP можно создавать и через Rar.exe (с ключом -afzip), и через
   7z.exe. Но учтите: ZIP не поддерживает шифрование имён файлов,
   поэтому галочка «шифровать имена» для ZIP недоступна.
   Внимание, для ZIP выбирайте 7-Zip, т.к. через RAR пока не работает.

В: Где взять Rar.exe или 7z.exe?
О: Rar.exe устанавливается вместе с WinRAR, 7z.exe — вместе с 7-Zip.
   Программа ищет их автоматически в стандартных местах и в PATH.
   Если не нашла — нажмите «Найти» или укажите путь вручную через «Обзор».

В: Почему архив получился чуть больше или чуть меньше исходников?
О: Видео практически не сжимается, поэтому размер архива почти равен сумме
   исходных файлов. Небольшая разница — это служебные заголовки архива.
   Для хорошо сжимаемых данных (текст, фото) разница будет заметнее.

В: У меня в папке 12 000 файлов. Программа справится?
О: Да. Начиная с версии 2.2 программа передаёт список файлов архиватору
   через @listfile, поэтому ограничение Windows на длину командной строки
   (около 32 767 символов) больше не мешает. Но учтите: если файлов
   больше 2000, они будут разбиты на несколько архивов, даже если по
   размеру могли бы влезть в один. Это сделано специально, чтобы
   файл-список не разрастался до гигабайта.

В: Что такое «дозаполнение» в режиме «Гибрид»?
О: Если после создания архива он заполнен менее чем на 85% от лимита,
   программа берёт файлы из следующего набора и добавляет их в текущий
   архив, пока они влезают по размеру. Это делает архивы плотнее,
   особенно если в папке много мелких файлов. Работает и для RAR, и для
   7-Zip. Количество попыток дозаполнения задаётся параметром
   «макс. попыток» (по умолчанию 3).

В: Что будет, если файл занят другой программой?
О: Программа пропустит его, запишет в лог и продолжит работу. В конце
   вы увидите список предупреждений.

В: Можно ли прервать работу?
О: Да, кнопкой «⏹ Стоп». Текущий недоделанный архив будет удалён, чтобы
   не оставлять мусор.

В: Где хранятся настройки?
О: В файле "%USERPROFILE%\.arch_grouper_settings.json". Он создаётся
   автоматически при первом запуске и обновляется при старте архивации.

В: Программа что-то отправляет в интернет?
О: Нет. Всё работает локально. Интернет нужен только для открытия ссылок
   GitHub / Telegram из окна «О программе».
